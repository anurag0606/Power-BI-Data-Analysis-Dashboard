# 🧩 Overview

This Power BI project provides a comprehensive analysis of OLA ride
booking data. The dashboard helps monitor booking trends, revenue, ride
success, cancellations, vehicle performance, payment methods, and
customer & driver ratings.

---

# 🎯 Business Problem

Ride-hailing companies need to monitor operational performance and
customer experience.

This dashboard answers questions such as:

- How many rides were booked?
- What is the booking success rate?
- Which vehicle types perform best?
- Which payment methods generate the highest revenue?
- Why are rides cancelled?
- How do customers rate drivers and rides?

---

# 📁 Dataset

The dataset contains OLA ride booking information.

### Main Columns

- Booking ID
- Date
- Customer ID
- Vehicle Type
- Booking Status
- Ride Distance
- Booking Value
- Payment Method
- Driver Rating
- Customer Rating
- Cancellation Reason

# 📈 Key Business Insights

- Most rides were successfully completed.
- Cash and UPI contribute the highest booking value.
- Prime Sedan and E-Bike show strong booking performance.
- Customer and driver ratings remain close to 4.0.
- Cancellation analysis helps identify operational improvement areas.
