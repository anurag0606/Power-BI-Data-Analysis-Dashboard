# 📊 Power BI Dashboards

This repository contains a collection of Power BI dashboards created to analyze different datasets.  
Each folder includes:

- `.pbix` → Power BI dashboard file
- `.xlsx/.csv` → Dataset used (if included)
- `screenshot.png` → Preview of dashboard
- `README.md` → Details about the specific dashboard

## 📂 Dashboards Included

1. **Data Professional Salary & Survey Analytics** → Insights into survey results of data professionals.
2. **E-commerce Retail Analytics Dashboard** → Sales performance, revenue, and customer trends.
3. **Healthcare Analytics Dashboard** → Patient records, admissions, and treatment statistics.
4. **Ola Ride Analytics Dashboard** → Ride data, revenue, and driver performance.
5. **Virat Kohli Statistics Dashboard** → Batting performance and cricket career highlights.
6. **Retail Sales Performance Dashboard** → Finished sales report for overall KPIs.
7. **Covid-19 Global Analysis Report Dashboard**
8. **Swiggy and Zomato Retail Analytics Dashboard**

## 🚀 How to Use

1. Go inside the folder of the dashboard you want.
2. Download the `.pbix` file.
3. Open it with **Power BI Desktop**.
4. (Optional) Download the raw dataset to explore/refresh data.
