# 📊 Retail Sales Performance Dashboard

*An interactive Power BI dashboard designed to analyze retail sales
performance, customer behavior, product trends, and budget achievement.*

## 📌 Overview

This dashboard analyzes retail sales, customers, products, budgets, and
regional performance using interactive Power BI visuals.

## 🎯 Business Problem

This dashboard helps answer: - Are sales meeting budget? - Which
customers generate the highest sales? - Which products perform best? -
Which cities contribute the most revenue? - How do monthly sales compare
with budget?

## 📁 Dataset

-   Customer
-   Customer City
-   Product
